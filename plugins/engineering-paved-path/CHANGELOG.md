# Changelog

All notable changes to `engineering-paved-path` are documented here. The format follows [Keep a Changelog](https://keepachangelog.com), and the plugin uses [semver](https://semver.org).

## [1.0.0] - 2026-10-16
- Initial release with 13 skills: `onion-architecture`, `frontend-architecture`, `mermaid-diagram`, `skill-routing`, `security`, `typescript-expert`, `react-best-practices`, `next-best-practices`, `react-testing-library`, `fastify-best-practices`, `drizzle-orm-patterns`, `postgresql-table-design`, `zod`
- Generalized `onion-architecture` and `frontend-architecture` to a reference layout that your repository's architecture docs override
- Added `skill-routing`, the file-to-skill table that agents use to load only the skills a diff needs
- Added eight `claude plugin eval` review cases for `onion-architecture`
